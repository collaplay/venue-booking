# CollaPlay 報價單系統

掛在場租系統後台：登入管理員帳號後，側邊選單點「報價單」（網址 `/dashboard/quote`）。

## 怎麼用

1. 填完後按「列印／存 PDF」，用瀏覽器另存為 PDF 輸出報價單
2. 客人付全額時，在「付款」勾「全額付款」，就不會印訂金、尾款；「確認後幾天內匯款」的天數會帶進條款
3. 「儲存草稿」可以把填到一半的報價單存成檔案下載到自己電腦（副檔名 .json），之後用「開啟草稿」接著改

## 檔案

| 檔案 | 用途 |
|------|------|
| `index.html` | 報價單畫面 |
| `config.js` | 價格、空間、餐飲、條款：**改價格或條款只動這個檔** |
| `pricing.js` | 計價規則（場租方案、超時、攝影、非營業時段人事費） |
| `test.js` | 計價自我檢查，改完 `pricing.js` 後跑 `node quote-tool/test.js`，印出 `ok` 才算對 |
| `../app/dashboard/quote/route.ts` | 把上面的檔案組成一頁送出，並檢查管理員登入 |

## 給 Claude Code 的說明

- 價格／條款／品項 → 改 `config.js`
- 計價邏輯 → 改 `pricing.js`，改完跑 `node quote-tool/test.js`
- 自己新增的點心存在瀏覽器 localStorage，換電腦或清瀏覽器資料會消失；要永久保留就寫進 `config.js` 的 `pastries`
- 改完照場租系統的流程走：feat branch → PR → merge 進 master 後自動部署

## 注意

這個 repo 是公開的，匯款帳號不寫進 `config.js`，放在 Vercel 環境變數 `QUOTE_BANK_ACCOUNT`（本機開發放 `.env.local`）。
