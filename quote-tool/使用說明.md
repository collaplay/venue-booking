# CollaPlay 報價單系統

掛在場租系統後台，只有管理員帳號能用。有兩個入口：

- **從專案開（平常用這個）**：專案頁按「建立報價單／開啟報價單」，網址 `/dashboard/quote?project=<專案 id>`
- **空白報價單**：側邊選單點「報價單」（`/dashboard/quote`），給還沒建專案的詢價用；不會存到系統裡

## 專案是唯一的資料來源

活動名稱、客戶資料、檔期、場地費都以專案為準，報價單上這些欄位是鎖住的，要改請回專案改。

在專案的每個檔期填：

- 計價方案、國定假日 → 系統自動算出標準價，按「帶入標準場地費」填進場租金額
- 長期合作折扣（整個專案一個值，填在第 1 筆檔期，例：85＝85 折）
- 議價理由（場租金額跟標準價不同時填，只有內部看得到）

報價單上每個檔期印一列，金額就是專案裡那筆的場租金額（已含折扣，不另外列折扣行）。客人要看到各空間分開的金額時，在專案裡把檔期拆成兩筆。

## 在報價單上做的事

1. 加購（飲品、點心、餐飲、攝影等）、付款方式、其他備註在這裡填。備註每一行會成為一條條款
2. 按「儲存到專案」，草稿存在系統裡，任何同事、任何電腦開同一個專案都看得到
3. 加購合計跟專案的餐飲費不同時，儲存會跳出視窗問要不要把金額寫回專案（寫在最早的那筆檔期）
4. 按「列印／存 PDF」，用瀏覽器另存為 PDF。固定兩頁：第一頁明細與匯款資訊，第二頁條款
5. 報價日期每次開啟自動帶當天；匯款期限與報價有效期預設都是 3 天
6. 客人付全額時勾「全額付款」，就不會印訂金、尾款
7. 說明欄：數量是 1 的品項留白

空白報價單的「儲存草稿／開啟草稿」是把檔案下載到自己電腦（.json），只有那台電腦有。

## 檔案

| 檔案 | 用途 |
|------|------|
| `index.html` | 報價單畫面與列印版面 |
| `config.js` | 價格、空間、餐飲、條款：**改價格或條款只動這個檔** |
| `pricing.js` | 計價規則（場租方案、超時、攝影、非營業時段人事費、折扣） |
| `test.js` | 計價自我檢查，改完 `pricing.js` 後跑 `node quote-tool/test.js`，印出 `ok` 才算對 |
| `logo.png` | 印在每頁底部的 logo |
| `../app/dashboard/quote/route.ts` | 把上面的檔案組成一頁送出、檢查管理員登入、帶入專案資料、存草稿 |
| `../lib/quote/prefill.ts` | 專案資料轉成報價單內容 |
| `../lib/quote/standard-price.ts` | 專案表單裡的標準價計算（跟報價單共用 `config.js`、`pricing.js`） |

## 給 Claude Code 的說明

- 價格／條款／品項 → 改 `config.js`；專案表單的標準價會跟著變
- 計價邏輯 → 改 `pricing.js`，改完跑 `node quote-tool/test.js`
- 草稿存在資料表 `project_quote_draft`（一個專案一筆）；開啟時專案來的欄位會蓋過草稿
- 自己新增的點心存在瀏覽器 localStorage，換電腦或清瀏覽器資料會消失；要永久保留就寫進 `config.js` 的 `pastries`
- 這份工具原本是 Raymond 的獨立版本，現在以 repo 裡這份為準
- 改完照場租系統的流程走：feat branch → PR 到 dev → dev 發 PR 到 master，merge 後自動部署

## 注意

這個 repo 是公開的，匯款帳號不寫進 `config.js`，放在 Vercel 環境變數 `QUOTE_BANK_ACCOUNT`（本機開發放 `.env.local`）。
